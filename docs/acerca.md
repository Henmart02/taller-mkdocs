# Acerca del proyecto

Este proyecto fue realizado como práctica para aprender a crear sitios de documentación con MkDocs.

## Herramientas utilizadas

- Python
- MkDocs
- Material for MkDocs
- Markdown
- GitHub Pages

## Buenas prácticas aplicadas

- Se organizaron los contenidos en varias páginas.
- Se usaron enlaces internos.
- Se agregó una tabla.
- Se agregó una imagen dentro de `docs/img/`.
- Se usaron bloques de código.
- Se agregaron bloques de admonición.

!!! warning "Importante"
    Es recomendable usar rutas relativas para imágenes y enlaces, ya que esto facilita que el sitio funcione correctamente al publicarlo.
